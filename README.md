# 習慣トラッカー

スマホのホーム画面に追加して使う、オフライン対応の習慣トラッカー (PWA)。
データは端末のブラウザ (localStorage) の中だけに保存し、外部のサービスやライブラリは使わない。

## できること

- 習慣の追加 (名前は 30 文字以内、同じ名前は不可)
- 今日の分のチェック (もう一度押すと外れる)
- 連続日数の表示 (今日が未チェックでも、昨日まで続いていれば途切れていない扱い)
- 今月の記録をカレンダーで表示
- バックアップの書き出しと読み込み (JSON ファイル)
  - 読み込むときは、このアプリで書き出した形か (項目の過不足・日付・重複など) を確かめ、
    今のデータを置き換えてよいかを確認してから置き換える
  - 保存データが壊れて読めなくなったときも、読み込みで元に戻せる

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面 |
| `habits.js` | 画面に関係しない処理 (日付計算・連続日数・保存と読み込み) |
| `habits.test.js` | `habits.js` のテスト |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面への追加とオフライン動作 |
| `tools/make-icons.py` | アイコンを作り直すスクリプト |
| `sample-backup.json` | 読み込みを試すための練習用データ |

## テスト

```sh
npm test   # node --test と同じ。Node.js 18 以上
```

## スマホのホーム画面に追加する

公開先の URL は `https://<GitHub のユーザー名>.github.io/habit-pwa/`。
どちらの端末でも、最初の 1 回は通信できる状態で開く (そのときにオフライン用のファイルが端末に保存される)。

### iPhone (Safari)

1. Safari で上の URL を開く。
2. 画面下の共有ボタン (四角から上向きの矢印が出ているアイコン) を押す。
   見当たらないときは、アドレスバーの横の「…」を押すと出てくる。
3. 一覧を下へ送って「ホーム画面に追加」を押す。
4. 名前 (「習慣」) を確かめて、右上の「追加」を押す。
5. 以後はホーム画面の「習慣」アイコンから開く。

iPhone では、Safari のタブで開いたときと、ホーム画面のアイコンから開いたときとで、保存されるデータが別々になる。
記録はホーム画面のアイコンから開いて付けること。

### Android (Chrome)

1. Chrome で上の URL を開く。
2. 右上の「⋮」(縦に 3 つの点) を押す。
3. 「アプリをインストール」または「ホーム画面に追加」を押す。
   「ホーム画面に追加」の場合は、続けて「インストール」を選ぶ。
4. 確認画面で「インストール」を押す。
5. 以後はホーム画面 (またはアプリ一覧) の「習慣」アイコンから開く。

### 注意

- 記録はその端末の中だけにあるので、機種変更やアプリの削除をすると消える。ときどき「書き出す」でバックアップを取ること。
- アプリを消すと記録も消える。消す前に書き出しておくこと。

## パソコンで試す

Service Worker は `file://` では動かないので、ローカルのサーバー経由で開く。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8765/ を開く
```

## バックアップの形式 (version 1)

```json
{
  "version": 1,
  "exportedAt": "2026-11-09T12:00:00+09:00",
  "habits": [
    { "id": "…", "name": "朝の散歩", "createdAt": "2026-11-09", "doneDates": ["2026-11-09"] }
  ]
}
```

日付は端末の地方時の `YYYY-MM-DD`。読み込めるのは、この 3 項目と、習慣ごとの 4 項目が過不足なくそろったファイルだけ。
端末の中には `exportedAt` を除いた形で保存している。

## 更新するとき

アプリのファイルを変えたら、`sw.js` の `CACHE_NAME` の番号を上げる (上げないと古いキャッシュが表示され続ける)。
